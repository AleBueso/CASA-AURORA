# CASA-AURORA
# Casa Aurora · Control de lotes y pedidos

**Código de verificación:** `LEARN-CAP-1E72416E`

Sistema web para **Casa Aurora**, emprendimiento de vino artesanal de flor de Jamaica en Danlí, El Paraíso (Honduras). Proyecto de la clase **Ingeniería de Software 1**.

## Problema

Los pedidos y reservas se anotan en un cuaderno o en el celular solo cuando hay uno cerca. Se olvidan encargos y fechas de entrega, y no hay control de cuántas botellas hay disponibles en cada lote.

## Feature

Registro de pedidos y reservas conectado a los lotes de producción: controla en qué va cada lote y asigna los pedidos por orden de llegada.

## Tecnologías

- Java + Spring Boot
- SQL Server
- HTML, CSS y JavaScript
